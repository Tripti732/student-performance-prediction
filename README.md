## 📌 Project Overview

This repository contains the **Week 1 Task Submission** for the Virtual Data Science Explorer Internship at YuvaIntern (NSDC Partner).

The project focuses on building a **Machine Learning model** to predict student academic performance (Pass / Fail / At-Risk) using Python, based on features like attendance, GPA, family income, and access to resources.

## 🎯 Project Objectives

- Predict student academic performance using classification models
- Perform EDA to uncover patterns in student data
- Identify top features influencing academic outcomes
- Evaluate models using Accuracy, F1-Score, and ROC-AUC
